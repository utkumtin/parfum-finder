# schema/

`jsonschema` doğrulama dosyaları: `site.schema.json`, `platform.schema.json`. Bunlar
`sites/`/`platforms/` altındaki *örnekleri* değil, o örneklerin uyması gereken *şemayı*
tanımlar. Bozuk bir profilin yükleme anında açık hata vermesini sağlayan katman budur.

Şu an boş: iki şema dosyası da henüz yazılmadı.
